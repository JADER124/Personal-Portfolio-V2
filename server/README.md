# Server — Backend (futuro)

Carpeta reservada para el backend cuando el portafolio escale.

Stack sugerido cuando se implemente:
- **Runtime**: Node.js 22 + TypeScript
- **Framework**: Express o Fastify
- **BD**: PostgreSQL (proyectos, mensajes de contacto)
- **ORM**: Prisma
- **Auth**: JWT (si se necesita área privada)

## Arrancar

```bash
# Desde la raíz del monorepo
npm run dev:server
```
