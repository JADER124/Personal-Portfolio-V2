# Portafolio — Jhon Jader López Blandón

Portafolio personal con temática de expediente alienígena clasificado. El visitante desbloquea 5 niveles de autorización que revelan las secciones: identificación, habilidades, proyectos, experiencia y contacto.

**Demo:** _próximamente_

## Stack

- React 18 + Vite 5 + TypeScript
- CSS Modules + variables CSS
- Framer Motion

## Desarrollo local

```bash
cd client
npm install
npm run dev
```
